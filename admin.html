📦 Generated Config JSON
Copy this JSON and commit it to your GitHub repo as sports-evo-config.json. The widget fetches it on every load. No server needed — GitHub raw URLs work perfectly.

🌍 GitHub Raw URL for Widget
After uploading sports-evo-config.json to your GitHub repo, paste the raw URL into the widget's ADMIN_CONFIG_URL constant at the top of widget.html.

Raw URL pattern:
https://raw.githubusercontent.com/YOUR_USER/YOUR_REPO/main/sports-evo-config.json
📖 Quick Setup Guide

Step 1 — Fork or create a GitHub repo
Create a public GitHub repo (e.g. sports-evo-api) under your account.


Step 2 — Enable GitHub Pages
Go to repo Settings → Pages → Source: Deploy from branch → main → / (root). Save.


Step 3 — Upload this admin panel
Commit admin.html to the repo root. Access it at:
https://YOUR_USERNAME.github.io/YOUR_REPO/admin.html


Step 4 — Configure & export
Fill in all settings in this panel. Click Save & Export, then download sports-evo-config.json and commit it to the repo root.


Step 5 — Point the widget
In widget.html, set:
const ADMIN_CONFIG_URL = 'https://raw.githubusercontent.com/YOUR_USER/YOUR_REPO/main/sports-evo-config.json';


Step 6 — Add redirects for matches
Go to the Redirects tab. Add match IDs (from the API) and their stream URLs. Save & commit the new JSON.


Updating later
Just open the admin panel, make changes, download the JSON, and commit. The widget picks up changes within 30 seconds.
